Authentication

Pass your API key as a Bearer token in the Authorization header, or as a key query parameter:

# Header (recommended)
Authorization: Bearer ail_your_key_here

# Query parameter
GET /api/v1/registry?key=ail_your_key_here

REST endpoints

GET /api/v1/registry
List all sites in the registry. Paginated, filterable by topic and location.
topicFilter by tag or category keyword (e.g. plumber, ecommerce)
locationFilter by city, region, or country (e.g. Sydney, Australia)
pagePage number, default 1
limitResults per page, max 100, default 50
GET /api/v1/search?q=
Natural language search across the registry — names, descriptions, tags, and locations. Returns up to 20 ranked results.
qSearch query, e.g. motorcycle parts Sydney
GET /api/v1/site/:domain
Look up a specific site by domain name.
:domainDomain name, e.g. example.com (no https://)
# Search example
curl -H "Authorization: Bearer ail_your_key_here" \

MCP — native AI agent integration

⬡ Model Context Protocol

AILattice exposes an MCP-compatible endpoint so AI assistants (Claude, Cursor, and any MCP-aware agent) can query the registry as a native tool — no custom code needed.

Endpoint

POST https://ailattice.io/api/mcp
Authorization: Bearer ail_your_key_here
Content-Type: application/json

Available tools

search_registry
Search by keyword, topic, or location. Returns up to 10 ranked results.
get_site
Look up a specific domain in the registry.
list_registry
List the registry, filtered by topic and/or location.

Claude Desktop config

// claude_desktop_config.json
{
  "mcpServers": {
    "ailattice": {
      "command": "npx",
      "args": ["-y", "mcp-remote"],
      "env": {
        "MCP_SERVER_URL": "https://ailattice.io/api/mcp",
        "MCP_API_KEY": "ail_your_key_here"
      }
    }
  }
}

Direct JSON-RPC call example

curl -X POST https://ailattice.io/api/mcp \
  -H "Authorization: Bearer ail_your_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "search_registry",
      "arguments": { "q": "accountant london" }
    }
  }'

Python / OpenAI-style agent

import requests

def search_ailattice(query, api_key):
    r = requests.post(
        "https://ailattice.io/api/mcp",
        headers={"Authorization": f"Bearer {api_key}"},
        json={
            "jsonrpc": "2.0", "id": 1,
            "method": "tools/call",
            "params": {"name": "search_registry", "arguments": {"q": query}}
        }
    )
    return r.json()["result"]["content"][0]["text"]
