Quickstart

Two paths to conformance

The easy path gets you live in two minutes. The correct path is the full implementation — no difference to the outside world, but the deeper your constitution, the more AI agents can actually do for you.

Drop a plain-text file at https://yourdomain.com/intro.txt. That's it. Any conforming AI agent or crawler will find it automatically.

intro.txt 
# intro.txt — Introduction Layer declaration
# Spec: https://ailattice.io/paper

name:           Acme Corp
canonical_url:  https://acme.com
category:       SaaS / Project Management
mission:        Help teams ship software without the chaos.

core_belief:    Good tooling gets out of your way.

principles:
  - Clarity over completeness
  - Speed is a feature
  - The team is the product

constraints:
  - Will never sell user data to third parties
  - Will never lock exported data in proprietary formats
  - Will never charge for data export

what_this_is_not:
  - Not a replacement for version control
  - Not a reporting tool for executives
  - Not suitable for regulated industries requiring audit trails

constitution_url:  https://acme.com/constitution
1

Create the file

Copy the template above. Fill in your own name, mission, principles, constraints, and what_this_is_not. Be specific. Constraints are prohibitions — say what you will never do.

2

Upload to your site root

Place the file at /intro.txt. Must be publicly accessible at https://yourdomain.com/intro.txt. Serve as text/plain.

3

Verify with the validator

Run the validator against your domain. It checks for the required fields and flags anything missing.

4

List in the registry (optional)

Once validated, submit to the registry for certification and discoverability. Free forever.

The full implementation: compile a .ic constitution file and serve it at GET /constitution. The intro.txt is the authoring format; /constitution is what agents consume.

acme.ic — constitution source 
# constitution.ic — Full Introduction Layer constitution
# Spec: https://ailattice.io/paper  Section 6

name:               Acme Corp
canonical_address:  https://acme.com
category:           SaaS / Project Management
mission:            Help teams ship software without the chaos.
core_belief:        Good tooling gets out of your way.

principles:
  - Clarity over completeness
  - Speed is a feature
  - The team is the product

constraints:
  - Will never sell user data to third parties
  - Will never lock exported data in proprietary formats

what_this_is_not:
  - Not a replacement for version control
  - Not a reporting tool for executives

evaluation_criteria:
  - Does this action protect user data ownership?
  - Does this reduce friction for the team?
  - Is this reversible if wrong?

meta:
  version:          1.0.0
  authored_by:      Acme Corp
  last_reviewed:    2026-08-01
  status:           approved
Express / Node.js — serve at GET /constitution 
const constitution = require('./acme.ic.json');

app.get('/constitution', (req, res) => {
  res.setHeader('Content-Type', 'application/constitution+json');
  res.json(constitution);
});
1

Author your constitution

Fill in all required fields from Section 6 of the spec. evaluation_criteria is required here (not in intro.txt). Use the constitution builder if you'd rather not start from scratch.

2

Serve at GET /constitution

Your server must respond to GET /constitution with the compiled JSON constitution and Content-Type: application/constitution+json. See conformance test C5.1.

3

Also serve intro.txt

Maintain an /intro.txt as the human-readable authoring source. Both paths are complementary. Agents may read either.

4

Run conformance tests

Use the validator or the open-source test suite in /conformance of the GitHub repo to verify all REQUIRED tests pass.

Registry API

Query the registry

The registry is publicly queryable. Look up any certified site, search by topic or location, verify certification status. Free with a rate limit. Higher limits on paid plans.

Authentication 
# API key on signup — free tier: 100 requests/day
# Include in every request header

Authorization: Bearer YOUR_API_KEY
Method Endpoint Description
GET /api/registry List certified sites. Supports ?topic=, ?location=, ?limit=, ?offset=
GET /api/registry/:domain Look up certification status and full record for a specific domain
GET /api/search?q= Natural-language search across the registry. Returns ranked results with constitution excerpts
POST /api/validate Submit a URL for Introduction Layer conformance check. Returns pass/fail per test category
GET /api/topics List all topic tags in the registry with counts
Example — look up a domain 
curl https://ailattice.io/api/registry/example.com \
  -H "Authorization: Bearer YOUR_API_KEY"

# Response
{
  "domain":       "example.com",
  "certified":    true,
  "certified_at": "2026-06-01T09:22:00Z",
  "name":         "Example Co",
  "category":     "SaaS / Developer Tools",
  "tags":         ["developer-tools", "api"],
  "constitution_url": "https://example.com/constitution"
}

Conformance

Test your implementation

16 tests across 5 categories. All REQUIRED tests must pass for AILattice certification. The full test suite is open source — use it on any implementation, conformant registries included.

C1

Constitutional Conformance

All required fields present and valid. Constraints are prohibitions, not aspirations. No operational state in stable fields.

5 tests — all required
C2

Evidence Coverage

If you're implementing an Evaluator: monotonicity in evidence and ambition, reproducibility within ±5 points, independence of generation and evaluation.

5 tests — all required
C3

Evaluator Output

Response schema conformance, outcome stability >85% on identical inputs, constraint violations correctly detected.

4 tests — all required
C4

Cognitive Entrypoint

For consuming systems: constitution must be retrieved before any entity-specific reasoning, tool invocation, or action planning.

1 test — required
C5

Discovery

GET /constitution returns a valid constitution at HTTP 200. intro.txt accessible at site root. Correct media type served.

1 required   3 recommended
